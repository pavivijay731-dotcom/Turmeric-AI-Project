Turmeric AI
 Project Overview

Turmeric AI is a web-based crop monitoring application designed to explore how AI-assisted technologies can help users understand common problems affecting turmeric crops through a simple and accessible digital platform.

The project was developed as part of an AI Immersion Project, focusing on identifying a genuine real-world agricultural problem and developing a digital solution to support crop monitoring and analysis.

Problem / Real-World Observation

During a real turmeric field visit, problems affecting the crop were observed and discussed.

The major problems identified include:

- Unhealthy and drying turmeric leaves.
- Possible disease or pest-related damage.
- Water-management difficulties.
- Risk of affected plants and crop loss.

The project explores how a web-based crop monitoring application can help users examine leaf images, view preliminary observations, and access general crop-monitoring recommendations.

Project Approach

The project follows a real-world problem-solving approach:

1. Visit the real location.
2. Observe and understand the agricultural problem.
3. Identify the major causes and challenges.
4. Design an AI-assisted solution concept.
5. Develop a web-based crop monitoring prototype.
6. Implement image upload and preview functionality.
7. Develop preliminary image colour-screening logic.
8. Display analysis observations and recommendations.
9. Develop a crop health dashboard.
10. Review the implementation and identify opportunities for further improvement.

Technical Direction

The project is implemented as a browser-based web application.

The technical implementation includes:

- HTML5 for website structure.
- CSS3 for styling and user interface design.
- JavaScript for user interactions and analysis logic.
- HTML Canvas API for preliminary image pixel-colour processing.
- Session Storage for temporarily retaining analysis results.
- GitHub for source code management.
- GitHub Pages for website hosting.
